# ⌨️ Keyboard Smash

## 🎮 Overview

Think you're fast enough? **Keyboard Smash** is a fast-paced keyboard reaction game that puts your speed, accuracy, and reflexes to the test.

Targets appear across an interactive on-screen keyboard, and you have to hit them using your physical keyboard before they disappear. But watch out for the **bombs**! 

Choose your difficulty, customize your game, and see how long you can survive!

## 🚀 Features

- ⌨️ Interactive on-screen keyboard
- 🎯 Randomly generated targets
- 💣 Surprise bomb targets
- ❤️ Lives and score system
- 🎚️ Multiple difficulty levels
- 🎮 Lives and Infinite game modes
- 🌗 Light & dark themes
- 🔊 Music and sound effects
- ✨ Animated UI and game interactions

## 🕹️ How to Play

- 🎯 **Smash the Targets!** — Hit every green target before it disappears.
- 💣 **Bombs Away!** — Watch out for bombs; hitting one costs you 2 ❤️.
- 📊 **Score. Survive. Repeat.** — Keep an eye on your score and lives.
- 💀 **Stay Alive!** — Don't run out of ❤️.
- ⚙️ **Set the Rules!** — Adjust the game to your liking.

## 🛠️ Tech Stack

- **React + TypeScript**
- **Vite**
- **TailwindCSS**
- **Motion** — animations
- **React Context API** — state management
- **HTML5 Audio** — sound
